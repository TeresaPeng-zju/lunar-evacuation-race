# 月球撤离赛 · Lunar Evacuation

双人实时月球车竞速的可玩俯视原型。使用原创灰黑月面工业场景，支持开局选路、一次实时落石、位置触发月震、秘密末段选路、共享余震与入区结算。

**在线游玩：<https://teresapeng-zju.github.io/lunar-evacuation-race/>**

> V0.1 是浏览器运动模拟，用于视觉、规则和路线验证。尚未连接实体机器人、相机或二维码读卡器，不能直接作为实体赛道控制系统。

## 启动

需要 Node.js 20 或更高版本，无第三方依赖。

```sh
npm run dev
# 打开 http://127.0.0.1:4173
npm test
```

亦可通过任意静态服务器托管 `dist/`。不要用 `file://` 打开（浏览器 ES 模块需要 HTTP）。运行不需要 API 密钥、账号、外部字体或 CDN。

## 玩法与操作

1. 双方各选开局路线。信标回廊正常 42 秒到末段岔路，废弃栈道 48 秒。选择先隐藏，点击“同时翻牌”后公开并发车。
2. 每人仅一张落石。系统选择对手已锁定路线前方最近的合法点，留足 2 秒预警与安全余量；无合法点不扣卡。车辆沿额外道路绕行，完成后障碍才消失。
3. 首车进入月震区，双方在 7 秒内选择碎隙捷径或归航环路。双方提交或超时后同时公开；超时默认归航环路。车辆持续行驶。
4. 首车到达捷径震源，进行一次 50% 塌陷判定，结果共享。先实际驶入停靠区获胜；0.1 秒内视为并列（模拟容差，实车需标定）。

| 操作 | 蓝方 | 黄方 |
| --- | --- | --- |
| 第一 / 第二张路线卡 | 1 / 2 | 8 / 9 |
| 落石 | Q | P |

空格暂停/继续，F 切换地面视图，Esc 或双击赛道退出地面视图。按钮同样支持鼠标和触摸。“自动演示”自动完成一局双人策略演示。

秘密选路仅在共享屏幕上隐藏提交结果，无法防止观察对方点击；正式展会需要独立选牌区域或设备。

## 双屏预览

控制窗口保持普通游戏页面；在**同一浏览器、同一来源**的另一个窗口打开 `dist/?floor=1`（本地开发使用 `http://127.0.0.1:4173/?floor=1`），拖到地面屏。通过 BroadcastChannel 同步完整游戏状态。仅打开一个控制窗口。地面窗口不推进模拟，不是跨设备联网。

模拟时间以渲染循环推进；后台标签页会被浏览器节流。现场测试需保持控制窗口可见。硬件版本应改为权威服务器时钟、定位事件与故障停机。

## 规则与暂定参数

| 项目 | 当前值 | 来源 |
| --- | --- | --- |
| 信标回廊到末段岔路 | 42 秒 | 原文明确 |
| 废弃栈道到末段岔路 | 48 秒 | 原文明确 |
| 归航环路 | 20 秒 | 原文明确 |
| 落石预警 / 选路窗口 | 2 秒 / 7 秒 | 原文明确 |
| 共享塌陷概率 | 50% | 原文明确 |
| 信标 / 外路落石额外路程 | 等价 10 秒 / 2 秒 | 暂定，保持原文 8 秒差值 |
| 末段落石额外路程 | 等价 5 秒 | 捷径原文明确；环路暂定 |
| 捷径稳定 / 塌陷 | 约 15.57 / 26.40 秒 | 暂定，由几何路径产生 |
| 并列容差 | 0.1 秒 | 暂定，仅模拟 |

车辆速度一致，所有时间差来自路径长度；没有扣速、等待或传送。普通环路完整局为 62 / 68 秒；稳定捷径可能约 58 秒完成。

## 项目结构

- `dist/engine.js`：纯状态机、几何路径、规则与位置事件。
- `dist/app.js`：Canvas 绘图、交互、音效与双屏广播。
- `dist/trails.js`：根据实际行驶历史铺设双轮车辙，支持转弯、绕行、双屏同步和复位清除。
- `dist/assets/tire-tracks.png`：用户提供的车辙素材，经透明底处理后用于动态轨迹。
- `dist/style.css`、`dist/index.html`：响应式指挥界面。
- `dist/assets/moon-terrain.png`：通过内置 imagegen 生成的原创底图。
- `tests/engine.test.mjs`：17 项 Node 内置测试。
- `server.mjs`：本地静态服务器。
- `ASSETS.md`：图像生成方式与完整提示词。

参考图 3.gif 仅作为风格方向，没有将来源不明的原图打包进公开仓库。底图中的工业设施仅为环境装饰。绘制道路尚未依据实车转弯半径、屏幕尺寸或定位精度标定。

## 验证

`npm test` 验证时间目标、距离惩罚、出发门槛、并列、暂停、合法落点、障碍持久性、秘密选路/超时、共享随机数、实际位置触发信标与震源、复合障碍可达性和路径连续性。浏览器人工验证自动演示、地图渲染、暂停、结算及按钮操作。正式活动仍需实车与观众试玩验收。
