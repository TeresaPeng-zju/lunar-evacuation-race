# Moonfall 科研站样板与全场景应用

本轮在已完成场景中精修 LAB_W 科研站，保留原有布局、玩法和双屏边界。图片均来自 Blender Cycles 或实际网页 WebGL，未使用生成图替代渲染。

## 同视角证据

- `blender-clay.png`：改进后几何的中性灰模。
- `blender-material-light.png`：同一工程的材质与灯光渲染。
- `game-before.png` / `game-after.png`：实际可玩入口修改前后截图，含原有 HUD。
- `station-study.blend`：可编辑工程，包含原场景、独立建筑部件、材质、打包的 AO 贴图和固定相机。
- `camera.json`：上述图片共用相机位置、目标点、16 单位正交宽度和 1600×1000 尺寸。Blender 的 Z 向上通过 `(x,y,z) → (x,z,-y)` 转为网页坐标。

实际游戏查看：`http://127.0.0.1:4176/?inspect=station`。去掉参数即回到正常全景，不影响状态机。

## 检查结果与处理

| 环节 | 原有差距 | 已实施改进 |
|---|---|---|
| 造型 | 大屋面空白，圆管状屋顶条显得像装饰；入口与窗面缺少厚度层次 | 保留主舱与气闸体块，改成扁平结构带、分层热控屋面、嵌套门框和清晰分缝 |
| 材质 | 旧资产法线尺度过大，金属表面出现不合尺度的坑点；窗户主要依赖一条亮线 | 缩小微法线影响，区分涂层外壳和金属屋面，增加克制的暖色窗面与门边灯 |
| 接缝与接地 | 网页屏幕空间遮蔽不能稳定保留全部细小凹槽 | 增加独立第二套 UV、1024² AO 图集，128 样本烘焙及降噪；网页 AO 强度 0.45，与已有 GTAO 配合 |
| 导出 | 额外 AO UV 如随整张月面合并，会给大量无关顶点增加数据 | 建筑和环境分组导出，避免地形携带无用 AO UV；保留 glTF 原有 PBR 与正确的 UV 通道 |
| 网页渲染 | Canvas 抗锯齿未覆盖后处理渲染目标，细边缘有锯齿 | 在输出色调映射前加入 SMAA，作用于实际游戏的整幅画面 |

首版低采样 AO 在网页产生颗粒，已在推广前修复。也修正了当前 Blender glTF 材质节点组接口兼容问题，使导出资产可以重新导入。

## 与参考图仍有的差距

参考图的建筑转角更统一、窗带和地坪组织更完整。样板的屋面、窗带与入口已形成较清楚的层次，但原有天线碟、周边货箱和部分地坪仍偏简化，本轮没有把这些全部重做。

Blender 使用 AgX，正式网页沿用已确认的 ACES、环境反射、GTAO 与方向光；两者相机一致，但不是像素级颜色一致。网页窗带更偏浅金，阴影更柔，Blender 的遮挡和反射更深。未用截图贴面来伪造一致性，也未为追求离线图效果改动游戏道路。

## 应用范围与维护

科研站样板已进入 `LAB_W`、`HAB_E`、`CAMP_W` 及补给设施的服务舱；保留不同设施原有范围与功能。实体展示用完整 3D 场景、独立虚拟赛道场景和三段行驶屏正俯视底图均沿现有流水线更新。采掘、通讯、飞船与中央遗址不做无关造型替换。

维护入口：

- `tools/refine_local_scene.py` 调用新增 `tools/station_finish.py`，在既有科研站上执行精修和烘焙。
- `tools/build_production_scene.py` 复用站房并导出正式 GLB。
- `tools/render_floor_arena.py` 保持原布局，重渲染三段底图。
- `dist/lunar-look.js` 保留建筑原始 PBR 与适度 AO；`dist/ruins-world.js` 加入 SMAA 和可选固定检查镜头。
- `npm run assets:build` 重建正式资源；`npm run assets:station-review` 输出灰模、材质图与可编辑样板。日常游戏仍为 `npm start`，不需要 Blender。

## 验证边界

- 83 项现有自动化测试通过。
- 实际网页 1× 模拟跑通：蓝方信标、黄方外路、落石预警和绕行、蓝方碎隙捷径／黄方归航环路、共享塌陷、双车停靠、结果、重置。黄方 72.34 秒、蓝方 77.92 秒到达。
- 行驶屏刷新后恢复相同比赛、位置和胜方；未发生资源加载失败或浏览器异常。
- 219 个受保护的根对象变换、地形顶点、道路、舱门、断层与锚点数据，和本轮前完全一致。
- 13 个既有规则、协议、地图／映射及受保护源文件哈希不变。
- 以上为模拟与渲染验证，没有连接实车，不是实体硬件验收。

最终运行检查：3456×1944 页面视口下，沿用自适应渲染分辨率 1788×1006，当前电脑中位约 30 FPS（不是原生 3.5K 渲染）；1920×1080 行驶屏约 30 FPS。24 个科研站家族材质均保留 AO，网页实际使用第 2 套 UV，强度 0.45。
