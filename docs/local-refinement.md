# 局部造型复核 · 2026-11-24

此版本为待确认候选，不是全场景推广，也不视为美术验收通过。

## 查看

在仓库运行 `npm start -- --port 4175`，访问：

- 修改前：`http://127.0.0.1:4175/look-review.html?look=unified`
- 局部候选：`http://127.0.0.1:4175/look-review.html?look=unified&refinement=local`
- 建筑近景：在上述 URL 后加 `&view=building`。

预览只读一次比赛快照，不控制比赛。默认控制台、3D 游戏和行驶屏继续使用原场景。不要用 `file://` 打开 Three.js 页面；它需要本地 HTTP 服务。

## 修改边界

- 保持此前 `lunar-look.js` 的光照、曝光、阴影和环境遮蔽。
- 道路只在西侧当前复核区域使用局部着色，降低黑色块面感；中心线、宽度、顶点 XYZ、分支状态与车辆运动不变。
- 仅精修 `LAB_W`：保留既有根节点锚点和天线资产，将分散十字构件收拢成连续主舱、附属舱、结构框架和独立入口。入口避开原有货箱，不移动货箱。
- 西侧视觉地形改为分层台地与坡折，调整原有三组岩体，压入接地基座；道路中心线两侧 3.5 世界单位内地形不参与雕刻。该距离仅是电脑展示场景的模型保护范围，不是实体车安全距离。
- 其余建筑、游戏逻辑、27 寸行驶屏、坐标映射及硬件协议保持不变。

## 可编辑资产与复现

- 源工程：`art/dual-screen/moonfall-dual-screen.blend`，未覆盖。
- 候选工程：`art/local-refinement/moonfall-local-refinement.blend`。
- 候选 GLB：`dist/assets/local-refinement/static-scene.glb`。
- 制作脚本：`tools/refine_local_scene.py`。从仓库根目录用 Blender 后台执行；只重建候选资产。
- 浏览器核验：`tools/verify_local_refinement.js`，使用 Playwright CLI `run-code --filename=...`，输出目录在脚本顶部。
- 导出合并必须以原有 `Geology_tile_0_0` 为活动对象；新建网格 UV 名称统一为 `UVMap`。否则合并后的 UV 通道顺序会导致地面纹理失效。

## 核验与限制

83 项既有测试通过。浏览器 10 项核验通过，包括同相机、1600×1000 同尺寸、164 条道路 XYZ 完全一致、灯光完全一致、既有材质贴图保留、无加载错误与不发比赛修改请求。18 个地图、逻辑、协议、行驶屏文件与上轮复核 SHA256 一致。Blender 中 196 个道路／门／断层相关网格的坐标哈希不变。

当前电脑 1600×1000 预览采样约 60 FPS；不是实体展示设备的性能验收。造型主次已有调整，但屋面材质层次及岩体自然度仍待视觉确认，不推广至其他建筑或全场景。
